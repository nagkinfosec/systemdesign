# RK's System Design Learning Guide

A static learning website for system design concepts, structured as a multi-phase guide with interactive and resource pages.

## Overview

This project is a client-side HTML learning guide focused on system design topics. It uses plain HTML and inline CSS for styling, making it easy to open locally in a browser.

## Project Structure

- `index.html` - Main landing page for the system design guide.
- `interactive.html` - Interactive learning page.
- `resources.html` - Resources and tools page.
- `pages/` - Dedicated pages for system design phases and additional content:
  - `AppSecurity.html`
  - `phase1.html`
  - `phase2.html`
  - `phase3.html`
  - `phase4.html`
  - `phase5.html`
  - `phase6.html`
  - `phase7.html`

## Usage

1. Open `index.html` in a web browser.
2. Navigate through the page links to explore the phases, security content, and resources.

## Notes

- The site is fully static and does not require a server, build tools, or dependencies.
- All styling is contained in each HTML file.

## Recommended Workflow

- Use this repository as a study guide or a base for expanding the system design content.
- Add new pages to the `pages/` folder for additional phases or topics.
- Keep styling consistent by following the existing inline CSS theme.
