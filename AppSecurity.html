Learn incident response
Gate 1: Design accepted? If threat modeling exposes unhandled risk, return to security requirements and architecture controls before coding.
Gate 2: Scans pass? If SAST, SCA, DAST, container, IaC, or secret scans fail, fix vulnerabilities and resubmit the build.
Gate 3: Threat detected? If telemetry flags a runtime issue, trigger incident response, contain the risk, and feed lessons back into engineering.
